
# 🌟 Nobitron - Crypto Investment Web App

**Nobitron** is a multilingual, visually stunning crypto investment platform that allows users to invest in stablecoin plans securely and easily.  
This app is fully customized based on CappoquinVIP's core with tailored upgrades, branding, and localized features.

---

## 🧩 Features

- 💸 **Investment Plans**: 30-day and 1-year options.
- 🌐 **Multilingual UI**: Supports Farsi, English, Russian, Arabic, Japanese.
- 🔐 **Secure Login**: Email-only registration & login. No OTP required.
- 📈 **Investment Growth Chart** (replaces traditional PnL chart).
- 🧑‍💼 **Support Panel**: Custom popup support under the brand name **"ژوپیتر"**.
- 🎨 **Beautiful Background**: Eye-catching, animated modern UI.
- 📲 **Trust Wallet Ready**: Direct payment link to:  
  `0x97633FAC680b3932C4CC47dd063a36a2D508c510`

## 🚀 Deployment

### Deploy to [Vercel](https://vercel.com)
You can deploy this app in minutes using:

1. Download ZIP file
2. Extract the files.
3. Go to [https://vercel.com/import/project](https://vercel.com/import/project)
4. Upload project files or connect via GitHub.
5. Select framework: `Other`
6. Set build output directory: `/`
